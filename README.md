## Відповіді на контрольні запитання:
1. Для малювання графіки на формі. Основні методи: DrawLine, DrawRectangle, DrawEllipse.

2. Pen малює контур лінії, а Brush повністю заповнює фігуру всередині.

3. Очищує екран білим кольором. Малювання має відбуватися у події Paint.

4. Normal, StretchImage, AutoSize, CenterImage, Zoom. StretchImage розтягує картинку на весь екран, а Zoom зберігає пропорції.

5. За допомогою методу Image::FromFile.

6. Керує видимістю об'єкта. Перемикаючи її значення, можна ховати або показувати картинку.

7. Номер вибраного елемента. Повертає мінус один, якщо нічого не вибрано.

8. Порівнює індекс вибраного рядка. При нульовому індексі виконується дія для першого елемента.

9. Компонент Timer, а швидкість задається властивістю Interval.

10. Клас SoundPlayer, а за завантаження і запуск відповідають методи Load та Play.
