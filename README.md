* **Опис роботи:** 
- Завдання 1. Ця програма реалізує циклічну анімацію по черзі трьох зображень за допомогою трьох таймерів із затримкою у пів секунди. Натискання першої кнопки запускає послідовну зміну кадрів, а другої — повністю зупиняє таймери та ховає зображення.
- Завдання 2. Інтерфейс: Вкладки (TabControl), список (ListBox) з елементами теми, кнопка Play та зображення (PictureBox) для кожної теми.
Робота: Програма перевіряє вибір елемента зі списку, визначає відповідний звуковий файл (.wav) та відтворює його за допомогою SoundPlayer.
